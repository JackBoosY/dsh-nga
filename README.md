# dsh-nga

在 DeepSeek Harness 里读 [NGA](https://bbs.nga.cn)（艾泽拉斯国家地理）的帖子。

装一次、登录一次，之后就可以对 Agent 说“帮我读 NGA 那个帖子”。

---

## 装

```
dsh plugin --profile web add github:JackBoosY/dsh-nga
```

装完**重启一次 DSH**（插件是启动时加载的）。

## 用

打开 **设置 → NGA**：

1. 填 NGA 的**账号**和**密码**；
2. 点 **「拿验证码」**，验证码图片会直接显示在框里；
3. **自己看图**，把上面的字填进去；
4. 点 **「登录」**。成功会显示 `已登录：uid …`。

之后 Agent 就能用 `nga_read` 读帖子：

> 帮我读一下 NGA 的 tid=18308359 那篇

要退出登录，点设置里那个「退出登录」。

## 它现在能做什么

- 读**一个帖子**的正文（可以指定页码、也可以只看某个作者 → “只看TA”）。

## 它现在不能做什么

- 发帖、回复、收藏、查看提醒（这些会动账号，还没做）；
- 搜索、看版面列表；
- 把帖子拆成“第几楼 / 谁 / 什么时候”的结构（现在是一整段文本）。

## 关于验证码（重要）

**这个插件不会去识别图形验证码。**

NGA 的验证码是一道写着“请人来”的门。它区分的是“有眼睛的人”和“没有眼睛的机器”，不是“真人”和“聪明的程序”。让程序去解它，等于把那道门拆掉——而且一旦能做到，**几乎所有网站的同类防线都会一起失效**。

所以这里的分工是：

- **图，插件拿；**
- **字，你填。**

## 关于凭证

- 账号密码**只用于这一次登录请求**，不会被保存；
- 登录成功后拿到的是 NGA 的 `access_uid` / `access_token`，**存在 DSH 自带的 credentials 服务里**（本机，不外传）；
- 想清掉：设置里点「退出登录」，或删掉 credentials 里 `dsh-nga/account` 这一条。
